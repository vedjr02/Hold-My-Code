# Hold My Code

A macOS menu bar app that keeps your Mac awake while coding agents work, even with the lid closed.

This repository only hosts the downloads.

**[Download the latest version](https://github.com/vedjr02/hold-my-code-releases/releases/latest/download/HoldMyCode.dmg)**

Requires macOS 14 or later, Apple Silicon or Intel. The app isn't notarized yet: on first launch,
allow it in System Settings › Privacy & Security › *Open Anyway*. The install guide inside the
disk image walks through it.
